A fast, dependency-free drop-in for marked 18.1.3: a from-scratch CommonMark 0.31.2 + GFM 0.29 renderer whose `parse(markdown)` returns byte-identical HTML to `marked.parse(markdown)` with marked's default options, in less CPU time. No dependencies, no build step — just `parse.js` and a small `main.ts` driver.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
